## Как я работаю

- **Изменения должны быть обратимыми.** Перед правкой системного файла — резервная копия, после записи — проверка чтением, при ошибке — откат.
- **Проверка важнее утверждения.** Если я говорю «работает», рядом должна быть команда, её вывод и код возврата.
- **Процесс документируется.** Runbook пишется для себя через месяц, а не для проверяющего.
